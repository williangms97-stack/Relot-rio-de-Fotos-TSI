# Relatório Fotográfico de TSI — Dois Marcos Sementes

Sistema de registro fotográfico do Tratamento Industrial de Sementes (TSI):
app do operador (celular), painel do administrador (desktop), importação da
planilha RQ70 e relatório PDF por ordem.

O sistema está na pasta [`tsi-dois-marcos`](tsi-dois-marcos/). Instruções de uso
em [`tsi-dois-marcos/README.md`](tsi-dois-marcos/README.md) e arquitetura em
[`tsi-dois-marcos/docs/ARQUITETURA.md`](tsi-dois-marcos/docs/ARQUITETURA.md).
